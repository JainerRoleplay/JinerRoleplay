# Установка админ меню для Garry's Mod

## Шаги установки:

1. Создайте папку `lua/autorun/` в директории вашего Garry's Mod сервера
   - Полный путь: `garrysmod/lua/autorun/`

2. Скопируйте все файлы админ меню в эту папку:
   - admin_menu.lua
   - admin_menu_config.lua
   - admin_menu_init.lua
   - admin_menu_players.lua
   - admin_menu_server.lua
   - admin_menu_utilities.lua
   - admin_menu_logging.lua
   - admin_menu_chat.lua

3. Опционально скопируйте example_usage.lua для дополнительных функций

4. Перезагрузите сервер или смените карту

## Проверка установки:

После перезагрузки сервера в чате должно появиться сообщение:
"Админ меню версии 1.0.0 загружено!"

## Использование:

1. Графический интерфейс: Введите `admin_menu` в консоль или `!admin` в чат
2. Команды чата: Используйте `!help` для просмотра всех доступных команд

## Настройка:

Откройте файл `admin_menu_config.lua` для изменения:
- Цветовой схемы
- Размера окна
- Включения/выключения функций
- Настроек логирования
- Горячих клавиш

## Требования:

- Garry's Mod сервер (не клиенсткая игра)
- ULX мод (опционально, для некоторых команд)
- Базовые права администратора

## Поддержка:

При возникновении проблем проверьте:
1. Корректность путей к файлам
2. Наличие всех необходимых файлов
3. Права доступа к файлам
4. Консоль сервера на наличие ошибок

Для дополнительной помощи обратитесь к файлу README.md
