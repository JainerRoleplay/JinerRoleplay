# Admin Menu для Garry's Mod
# Админское меню для Гаррис Мод

Современное и функциональное админ меню для Garry's Mod с красивым интерфейсом.

## 🚀 Возможности

### Управление игроками:
- ✅ Кик игроков с причиной
- ✅ Бан игроков (временный или постоянный)
- ✅ Убийство игроков
- ✅ Телепортация к игроку
- ✅ Телепортация игрока к себе
- ✅ Телепортация игрока по прицелу
- ✅ God Mode (бессмертие)
- ✅ Noclip (прохождение сквозь стены)
- ✅ Заморозка/разморозка игроков
- ✅ Лечение игроков
- ✅ Отбирание оружия
- ✅ Возрождение игроков

### Управление сервером:
- ✅ Очистка карты
- ✅ Смена карты
- ✅ Отправка оповещений всем игрокам
- ✅ Информация о сервере

## 📦 Установка

1. Скопируйте папку `adminmenu` в директорию `garrysmod/addons/`
2. Перезапустите сервер или пропишите `lua_refresh` в консоли

## 🔧 Настройка

### Добавление администраторов

Откройте файл `lua/autorun/server/sv_adminmenu.lua` и найдите секцию:

```lua
local admins = {
    -- Пример: ["STEAM_0:1:12345678"] = true,
    ["SUPERADMIN"] = true
}
```

Добавьте свой SteamID в список:

```lua
local admins = {
    ["STEAM_0:1:12345678"] = true,
    ["STEAM_0:0:87654321"] = true,
    ["SUPERADMIN"] = true
}
```

**Примечание:** Все супер-админы (IsSuperAdmin) автоматически имеют доступ.

### Узнать свой SteamID

1. Зайдите на сервер
2. Откройте консоль (~)
3. Напишите: `status`
4. Найдите свой SteamID в списке

## 💻 Использование

### Открыть меню:

В консоли (~) напишите:
```
adminmenu
```

Или:
```
adminmenu_open
```

### Управление игроками:

1. Откройте меню командой `adminmenu`
2. Выберите раздел "👥 Игроки"
3. Выберите игрока из списка
4. Нажмите нужное действие

### Управление сервером:

1. Откройте меню командой `adminmenu`
2. Выберите раздел "🖥️ Сервер"
3. Используйте доступные функции

## 🎨 Интерфейс

Меню имеет современный интерфейс с:
- Боковым меню навигации
- Списком игроков с информацией
- Панелью быстрых действий
- Цветовой индикацией (красный - опасные действия, синий - нейтральные, зеленый - безопасные)

## 🔒 Безопасность

- Все действия проверяются на сервере
- Доступ только для администраторов из списка
- Супер-админы имеют автоматический доступ

- Легковесное меню

- Оптимизированная сетевая передача

## 🐛 Решение проблем

**Меню не открывается:**
- Проверьте, что вы добавили свой SteamID в список администраторов
- Убедитесь, что вы используете правильную команду: `adminmenu`

**Действия не работают:**
- Проверьте консоль на ошибки
- Убедитесь, что аддон правильно установлен

**Список игроков пустой:**
- Нажмите кнопку "Обновить список игроков"
