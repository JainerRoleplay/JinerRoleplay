# Админ Меню для Garry's Mod

Полнофункциональное админ меню для Garry's Mod с графическим интерфейсом и командами чата.

## Функции

### Управление игроками
- **Кик** - Исключение игроков с сервера
- **Бан** - Блокировка игроков на определенное время
- **Телепортация** - Перемещение игроков между позициями
- **Заморозка** - Блокировка движения игроков
- **Шлепки** - Нанесение урона игрокам
- **God Mode** - Режим неуязвимости
- **Noclip** - Прохождение сквозь стены
- **Невидимка** - Скрытие игроков

### Управление сервером
- **Смена карт** - Быстрая смена игровых карт
- **Перезагрузка** - Перезапуск текущей карты
- **Очистка** - Удаление ненужных объектов
- **Команды** - Выполнение серверных команд
- **Настройки** - Изменение серверных переменных

### Утилиты
- **Спавн** - Создание NPC, энтити и пропов
- **Оружие** - Выдача оружия и боеприпасов
- **Исцеление** - Восстановление здоровья
- **Взрывы** - Создание взрывов
- **Скорость** - Увеличение скорости движения

### Логирование
- **Отслеживание действий** - Все действия админов записываются в логи
- **Экспорт логов** - Возможность сохранения логов в файл
- **Фильтрация** - Поиск по логам по различным критериям

## Установка

1. Скачайте все файлы админ меню
2. Поместите файлы в папку `lua/autorun/` на вашем сервере
3. Перезагрузите сервер или используйте команду `admin_reload` в консоли

## Использование

### Графический интерфейс
```lua
admin_menu
```
Или используйте команду чата:
```
!admin
```

### Команды чата
```
!help              - Показать все доступные команды
!kick <имя>        - Кикнуть игрока
!ban <имя> [время] - Забанить игрока
!goto <имя>        - Перейти к игроку
!bring <имя>       - Телепортировать игрока к себе
!slap <имя> [урон] - Нанести урон игроку
!freeze <имя>      - Заморозить игрока
!unfreeze <имя>    - Разморозить игрока
!god <имя>         - Включить/выключить God Mode
!noclip <имя>      - Включить/выключить Noclip
!invisible <имя>   - Включить/выключить невидимку
!map <карта>       - Сменить карту
!restart           - Перезагрузить карту
!spawn <класс>     - Заспавнить энтити
!logs [количество] - Показать логи
```

## Конфигурация

Откройте файл `admin_menu_config.lua` для настройки:

```lua
AdminMenu.Config = {
    Enabled = true,                    -- Включить админ меню
    RankRequired = "admin",           -- Минимальный ранг
    MenuTitle = "Админ Панель",      -- Заголовок меню
    MenuSize = {w = 850, h = 650},   -- Размер окна

    Features = {
        PlayerManagement = true,      -- Управление игроками
        ServerManagement = true,      -- Управление сервером
        Utilities = true,             -- Утилиты
        Settings = true,              -- Настройки
        Logs = true                   -- Логи
    }
}
```

## Цветовая схема

Настройте цвета в файле конфигурации:

```lua
AdminMenu.Config.Colors = {
    Background = Color(45, 45, 45, 255),
    Header = Color(65, 65, 65, 255),
    Button = Color(75, 75, 75, 255),
    ButtonHover = Color(95, 95, 95, 255),
    Text = Color(255, 255, 255, 255),
    Accent = Color(100, 150, 255, 255),
    Success = Color(100, 255, 100, 255),
    Warning = Color(255, 200, 100, 255),
    Error = Color(255, 100, 100, 255)
}
```

## Горячие клавиши

Настройте горячие клавиши:

```lua
AdminMenu.Config.KeyBindings = {
    OpenMenu = KEY_F3,        -- Открыть меню
    QuickTeleport = KEY_F4,   -- Быстрая телепортация
    QuickSpawn = KEY_F5       -- Быстрый спавн
}
```

## Логирование

Настройте систему логирования:

```lua
AdminMenu.Config.Logging = {
    Enabled = true,           -- Включить логирование
    LogFile = "admin_menu.log", -- Файл для логов
    LogActions = true,        -- Логировать действия
    LogChat = true,           -- Логировать чат команды
    LogLevel = 2              -- Уровень логирования
}
```

## Структура файлов

```

├── admin_menu_config.lua       # Конфигурация

├── admin_menu_players.lua      # Управление игроками

├── admin_menu_utilities.lua    # Утилиты и инструменты

```
