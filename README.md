# Advanced Admin Menu для Garry's Mod

Продвинутое админ меню для серверов Garry's Mod с полным функционалом управления игроками и сервером.

## Возможности

### 🔧 Основной функционал
- **Управление игроками**: кик, бан, телепорт, заморозка
- **Система мутов**: временное отключение чата
- **Режимы бога и ноклип**: специальные возможности для админов  
- **Система логирования**: запись всех админских действий
- **Многоуровневая система прав**: 4 уровня доступа (Helper, Moderator, Admin, SuperAdmin)

### 🎨 Интерфейс
- **Удобное GUI меню**: интуитивно понятный интерфейс
- **Горячие клавиши**: быстрый доступ к функциям
- **Цветовая индикация**: различие админов по уровням
- **Многоязычность**: поддержка русского языка

### 📋 Команды чата
- `!admin` / `/admin` - открыть админ меню
- `!menu` / `/menu` - альтернативная команда меню

### 💻 Консольные команды
- `admin_setadmin <игрок> <группа>` - выдать админ права
- `admin_removeadmin <игрок>` - убрать админ права  
- `admin_listadmins` - список всех админов
- `admin_listbans` - список активных банов
- `admin_unban <steamid>` - разбанить игрока
- `admin_reload` - перезагрузить конфигурацию
- `admin_save` - сохранить данные

## Установка

1. Поместите папку аддона в `garrysmod/addons/`
2. Перезапустите сервер
3. Настройте конфигурацию в `data/admin_menu/config.json`
4. Выдайте себе админ права: `admin_setadmin "ваш_ник" superadmin`

## Структура прав

### SuperAdmin (Уровень 100)
- Все команды и возможности
- Управление другими админами
- Доступ к серверным командам

### Admin (Уровень 50)  
- Баны и кики игроков
- Телепортация и управление
- Выдача денег (DarkRP)
- Смена карт

### Moderator (Уровень 25)
- Кик игроков
- Телепортация
- Заморозка и муты

### Helper (Уровень 10)
- Базовые команды телепортации
- Заморозка игроков

## Конфигурация

Основной файл конфигурации: `data/admin_menu/config.json`

```json
{
  "AdminLevels": {
    "superadmin": {
      "Name": "Супер Администратор",
      "Level": 100,
      "Color": [255, 0, 0],
      "Commands": "*"
    }
  },
  "Settings": {
    "LogActions": true,
    "NotifyPlayers": true,
    "SaveBans": true
  }
}
```

## Логирование

Все админские действия записываются в файлы:
- `data/admin_menu/logs/ГГГГ-ММ-ДД.txt` - логи по дням
- `data/admin_menu/admins.json` - список админов
- `data/admin_menu/bans.json` - активные баны
