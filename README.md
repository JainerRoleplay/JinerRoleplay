# Garry's Mod Admin Menu

Современная веб-админ панель для серверов Garry's Mod с системой разрешений и логированием действий.

## 🚀 Возможности

### Управление игроками
- **Кик игроков** - отключение игроков с указанием причины
- **Бан игроков** - временный или постоянный бан с детальным описанием
- **Телепорт к игрокам** - мгновенное перемещение к выбранному игроку
- **Наблюдение** - режим спектатора для мониторинга игроков
- **Список игроков** - отображение всех онлайн игроков с информацией о пинге

### Управление сервером
- **Смена карты** - переключение между доступными картами
- **Перезапуск сервера** - безопасный перезапуск с уведомлением игроков
- **Управление погодой** - изменение погодных условий (дождь, снег, туман, гроза)
- **Управление временем** - настройка времени суток и скорости его течения

### Админ команды
- **Выполнение команд** - интерфейс для ввода и выполнения админ команд
- **Быстрые действия** - предустановленные команды для частых операций

### Логи и статистика
- **Просмотр логов** - детальная история всех действий админов
- **Статистика сервера** - аналитика по игрокам и активности
- **Экспорт данных** - скачивание логов в различных форматах

### Система разрешений
- **Уровни доступа** - Супер Админ, Админ, Модератор, Помощник
- **Гранулярные разрешения** - точная настройка доступных действий
- **Автоматическое скрытие** - интерфейс адаптируется под уровень доступа

## 🚀 Установка и настройка

### 1. Загрузка файлов
Скопируйте файлы на ваш веб-сервер:
- `admin_menu.html` - основная админ панель
- `admin_permissions.js` - система разрешений

### 2. Настройка разрешений
Отредактируйте файл `admin_permissions.js` для настройки уровней доступа:

```javascript
// Изменение уровня текущего пользователя
this.currentUser = {
    id: 1,
    name: 'YourAdminName',
    steamid: 'STEAM_0:1:123456789',
    level: 'superadmin', // superadmin, admin, moderator, helper
    permissions: this.permissions.levels.superadmin.permissions
};
```

### 3. Интеграция с сервером
Для полной функциональности необходимо интегрировать с сервером Garry's Mod:

```lua
-- Пример интеграции с ULX/ULib
function AdminPanelKickPlayer(admin, target, reason)
    if ULib.ucl.query(admin, "ulx kick") then
        RunConsoleCommand("ulx", "kick", target, reason)
        -- Отправка лога в веб-панель
        SendLogToWebPanel(admin, "player.kick", target, reason)
    end
end
```

## 🔐 Уровни доступа

### Супер Админ
- **Доступ**: Все функции без ограничений
- **Цвет**: Красный (#ff6b6b)
- **Разрешения**: `['*']` (все)

### Админ
- **Доступ**: Управление игроками и сервером
- **Цвет**: Оранжевый (#ffa500)
- **Разрешения**: Кик, бан, телепорт, наблюдение, смена карты, погода, время

### Модератор
- **Доступ**: Базовое управление игроками
- **Цвет**: Зеленый (#00ff88)
- **Разрешения**: Кик, телепорт, наблюдение

### Помощник
- **Доступ**: Только мониторинг
- **Цвет**: Синий (#3742fa)
- **Разрешения**: Наблюдение, просмотр логов

## 📊 Система логирования

### Типы логов
- **Действия с игроками**: кик, бан, телепорт, наблюдение
- **Управление сервером**: смена карты, перезапуск, погода, время
- **Админ команды**: выполнение консольных команд
- **Системные события**: вход/выход админов, ошибки

### Метаданные логов
```javascript
{
    id: 1234567890,
    timestamp: "2024-01-15T14:30:25.000Z",
    admin: "AdminUser",
    action: "player.kick",
    target: "BadPlayer",
    details: "Причина: Нарушение правил",
    ip: "192.168.1.100",
    success: true
}
```

### Экспорт логов
- **JSON** - структурированные данные
- **CSV** - табличный формат для Excel
- **Фильтрация** - по админу, действию, дате, результату

```javascript
    // Настройка уведомлений

```

## 🐛 Устранение неполадок

### Частые проблемы

**Кнопки не работают**
- Проверьте подключение `admin_permissions.js`
- Убедитесь в корректности атрибутов `data-action`

**Не отображаются разрешения**
- Проверьте уровень пользователя в `admin_permissions.js`
- Убедитесь в корректности названий разрешений

**Логи не сохраняются**
- Проверьте функцию `saveLog()` в `AdminLogger`
- Убедитесь в доступности сервера для записи

### Отладка
Включите консоль разработчика (F12) для просмотра ошибок JavaScript.
